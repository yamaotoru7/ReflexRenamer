Reflex Renamer Help

A batch renamer for files and folders that supports wildcards, regular expressions, tag information and scripts

Overview

Reflex Renamer is a Windows application for renaming many files and folders at once. The list shows the new names as you type, and you can undo a rename after it has been run.

  • Rename: add strings or numbers, remove characters, convert case or fullwidth/halfwidth characters, and replace text. You can pick an item from the typical menu, or specify the details with wildcards, regular expressions or letter translation.
  • TagRename: use information stored in the files, such as ID3 tags of music files, EXIF data of photos, or properties of Office documents and PDFs, in the new names.
  • Attributes: change the timestamps (created, modified and accessed dates) and attributes (read-only, hidden and so on) of files and folders in one operation.
  • NumberedObject: create numbered empty files, empty folders or copies of a file in one operation.

You can also process everything under the subfolders, rename while moving or copying to another folder, and sort files into folders created per date or per tag.

Reflex Renamer runs on Windows 10 / 11 (64-bit). The user interface is available in Japanese, English, German, Spanish, French, Italian, Portuguese (Brazil) and Chinese (Simplified and Traditional).

Installing and uninstalling

Installing

Run the installer (ReflexRenamer-Setup-<version>.exe). It does not need administrator rights and installs to %LocalAppData%\Programs\Reflex Renamer. .NET is included, so nothing else needs to be installed.

When you install a new version over an existing one, the settings (Reflex Renamer.ini) and the undo log (Rename.log) are kept.

Uninstalling

Uninstall Reflex Renamer from Windows Settings › Apps. The folder context menu entry and the "Send to" menu entries registered in the options are removed at the same time. The settings and the log remain in the installation folder; delete the folder if you no longer need them.

Basic usage

  1. Choose the targets: with "Specify Folder", the contents of the folder selected in the folder list (or typed in the folder box) are the targets. With "Specify File", only the files and folders dropped from Explorer are the targets. This is useful for renaming the results of an Explorer search.
  2. Choose a function: select Rename, TagRename, Attributes or NumberedObject with the tabs.
  3. Set it up: fill in the input form from top to bottom. For Rename and TagRename, the "New Name" column of the list is updated as you type. Rows whose name will change are shown in bold.
  4. Run: use the button at the bottom of the input form. If items are selected in the list, only those are processed; otherwise all displayed items are processed (a confirmation message is shown in this case).
You can also open a folder by dropping files or folders onto the window or onto the Reflex Renamer icon.

Rename

Targets

  • Target: check whether files, folders or both are processed.
  • Filters: limit the names shown in the list with wildcards. Separate several filters with ; (for example *.jpg;*.png). A word without . is treated as an extension, so jpg is the same as *.jpg. An empty filter, * and *.* match everything.
  • Recursive Sub Folders: include the contents of subfolders in the list. "Depth" sets how many levels down to go (0 means no limit).

Advanced Rename

Check "Advanced Rename" to choose a rename method and write the search and replace freely.

Rename methodUsage
Wild CardUse * and ? in the search, and refer to the matched parts as \1–\9 in the replace. Only names that match as a whole stay in the list. → Wildcards
Reg ExpSearch with a Perl-compatible regular expression and replace the matched part. Only matching names stay in the list. → Regular expressions
TranslationList the characters to convert in the search and the resulting characters in the replace, in the same order; each character is replaced one by one (for example, search a-z and replace A-Z converts lowercase letters to uppercase). Ranges can be written with -.

Besides the matched parts, the replace can contain tags for the name, extension, folder name, date/time, number and more. The buttons to the right of the search and replace boxes open a menu of available symbols and tags; the selected one is inserted at the cursor.

  • Regular expression options: choose whether the search is case sensitive and whether only complete matches are shown.
  • Presets: save frequently used search/replace combinations and recall them from a menu. Use "Organize Presets" to reorder, rename or delete them.
  • Script: when checked, the replace is evaluated as a VBScript or JScript expression. → Scripts

Numbering

A ? in the replace inserts a sequential number at that position. The number of ? characters sets the number of digits (??? gives 000, 001, …).

  • Start and Step: the first number and the increment. The default is to start at 0 and increase by 1.
  • Reset by each folder: when subfolders are included, numbering restarts whenever the folder changes.
  • Number type: the button to the right of the numbering box lets you choose Decimal digit, Hexadecimal digit or Alphabetically.

Numbers are assigned in the order of the list. Click a column header to sort (numeric parts are compared by value), or use "Shuffle" in the column header context menu to sort randomly.

The box to the left of the run button lets you choose an operation other than renaming.

Running and undoing

  • Name conflicts: if a file with the new name already exists, a dialog lets you choose Retry, Skip, Skip All, Overwrite, Overwrite All or Auto Numbering. In Tools › Options... › Rename you can set it to add a number automatically instead of asking each time.
  • Failures: if a name cannot be changed (for example because the file is in use), you can choose Retry, Skip, Skip All or Cancel.
  • Undo: the "Undo" button (Ctrl+Z) reverts the last operation as a whole. Operations are recorded in Rename.log, so you can undo them even after closing the application.

The Options button menu lets you set the numbering, choose whether the timestamp tags use the modified date or the created date, and choose whether to hide protected operating system files from the list.

TagRename

Names files using information embedded in them (tags).

  1. Choose the tag type: Music <ID3>, Photo <EXIF>, Image <IPTC>, Document <DOC> or Web Page <HTML>.
  2. Check the extensions to process.
  3. Write the new name in "Format". Tags are written in angle brackets, such as <ID3.Artist>, and can be picked from the menu of the button to the right of the format box. The original extension is added to the new name automatically.
TypeInformation read
MusicID3v1 and ID3v2 (2.2–2.4) of MP3, WMA, APE, MPC and Ogg Vorbis. <ID3.*> prefers ID3v2; write <ID3v1.*> to use ID3v1 only.
PhotoEXIF of JPEG and TIFF (date taken, camera make and model, exposure, ISO speed and so on).
ImageIPTC (caption, author, keywords and so on).
DocumentDocument properties (title, author and so on) of Word, Excel and PowerPoint (legacy and Office 2007 or later formats) and PDF.
Web PageThe HTML <title>.

Check "Use File Property Info" to use the items shown in Explorer's "Details" (including items added by Windows or other applications) as tags. "Edit..." sets which items and target extensions each preset uses.

The date/time format of tags and the replacement for characters that cannot be used in names (\ / : * ? " < > |) can be changed in Options › TagRename (DateTime Format & Invalid Characters).

Numbering, the operation to perform, Undo and scripts work the same way as in Rename.

Attributes

Changes the timestamps and attributes of files and folders in one operation. "Recursive Sub Folders" is on by default.

Timestamp methodDescription
Specify DateTimeSets the created, modified and accessed dates to the given values.
ShiftMoves the current dates earlier or later by the given number of days and time.
Random GenerateSets random dates between the lower and upper limits.
Sequential GenerateAssigns dates at a fixed interval, forward or backward from a start date (in list order).
Make the SameSets the other dates to one of the created date, modified date, accessed date or photo date taken.

Shift, Random Generate, Sequential Generate and Make the Same change only the dates checked in "Apply To". Check "Modify Folder Timestamp" to change the dates of the folders themselves as well.

The attribute check boxes (Read-only, Archive, Hidden, System) have three states. Grayed items are not changed. Click "Start Modify" to run.

NumberedObject

Creates numbered files or folders in the open folder.

  • Kind of Target Object: empty file (specify the size; K, M and G can be used), file copy, empty folder or folder copy. For copies, choose the source file or folder.
  • Name: a sequential number is inserted where ? is written. The number of ? characters sets the number of digits (for example photo???.jpg).
  • Amount, Start from and Step: how many to create and how they are numbered.

The names to be created are shown in the list. Click "Start Create" to create them.

Tips

Editing new names directly

In Rename and TagRename, you can edit the "New Name" in the list by hand. Select an item and press F2, or click the new name. While editing, press ↑ or ↓ to move to the row above or below.

Sorting into folders

If the replace (the format in TagRename) contains a relative path with .. or /, folders are created and the items are moved into them. When numbering, check "Reset by each folder" to restart from 1 in each destination folder.

Example: sort photos into folders per date taken, one level up (replace ../\Y-\m-\d/\0)

Pictures\camera\IMG001.jpg  →  Pictures\2024-05-01\IMG001.jpg
Pictures\camera\IMG002.jpg  →  Pictures\2024-05-01\IMG002.jpg
Pictures\camera\IMG003.jpg  →  Pictures\2024-05-02\IMG003.jpg

Example: sort music files by artist and album (TagRename format <ID3.Artist>/<ID3.Album>/\t)

Group view

Right-click a column header in the list and use "Show in groups" to group items by folder, date, type or extension. In group view, numbering restarts for each group.

Example: replace \Y-\m-\d ?? with items grouped by date

2024-05-01 00.jpg
2024-05-01 01.jpg
2024-05-02 00.jpg   ← restarts at 00 when the date changes
2024-05-03 00.jpg
2024-05-03 01.jpg

Showing tags as columns

In TagRename, right-click a column header in the list; the second half of the menu lists the tags. The selected tag is added to the list as a column so you can compare its values across files. Select the same tag again to remove the column.

Scripts

When "Script" is checked, the replace or format is evaluated as a VBScript or JScript expression, and the result becomes the new name. Choose the language in the Script button menu.

  • Tags are expanded to their values before evaluation and become part of the expression. To treat a value as a string, enclose it in double quotation marks. For example, when \1 matches 123, "\1" & "\1" ("\1" + "\1" in JScript) gives 123123, and \1 + \1 gives 246.
  • The number ? is also expanded first. In scripts, * does not become a random number and can be used as an operator.
  • The Script button menu lists the bundled functions (fullwidth/halfwidth conversion, digit padding and so on) and the built-in functions of the language; the selected one is inserted at the cursor.
  • With "Edit Script", you can write your own functions in Script.vbs (Script.js for JScript). They are available from the next evaluation after saving. The bundled functions are in Script.Preset.vbs / Script.Preset.js and can serve as examples.
  • Items whose evaluation fails are not renamed.

Example: use the value of cell A1 on the first sheet of an Excel file as the file name (replace xls1stCell("\P\0") & "\e", with the following function in Script.vbs)

Function xls1stCell(path)
    Set excel = CreateObject("Excel.Application")
    Set book = excel.Workbooks.Open(path)
    xls1stCell = book.Sheets(1).Cells(1, 1).Value
    book.Close False
    excel.Quit
End Function
Microsoft is phasing out VBScript. If VBScript is no longer available in a future version of Windows, choose JScript.

Explorer integration

In Tools › Options... › General, you can register the following.

  • Folder Context Menu: adds "Reflex Renamer" to the menu shown when you right-click a folder in Explorer, so you can start the application with that folder open.
  • Add to "Send to" Menu: adds "Reflex Renamer (Rename)", "(TagRename)" and "(Attributes)", which pass the selected files to that page in "Specify File" mode.

You can also add the current folder to the Favorites menu (up to 20) to open it quickly. When the contents of the displayed folder change, the list is updated automatically.

Reference

Replace tags

Tags that can be used in the replace (the format in TagRename). They are replaced with the values of each file.

TagMeaning
\0The current name (including the extension)
\tThe file title (the name without the extension)
\eThe extension (without .)
\fThe name of the folder containing the file
\FThe name of its parent folder
\PThe full path of the folder containing the file (ends with \; useful in scripts)
\;The file size (with digit grouping)
\:The file size (without digit grouping)
\1–\9The parts matched by the search (in symbol order for wildcards, in parenthesis order for regular expressions)
?Sequential number. The number of ? characters sets the digits
*A random number
.. and /Move to the parent folder or a subfolder (sorting into folders)
\\A literal \

Date and time tags

Replaced with the file's modified date (can be changed to the created date in the options). Day and month names follow the Windows region settings. Put # after \ to omit leading zeros (\#m gives 5).

TagMeaningTagMeaning
\Y4-digit year\yLast 2 digits of the year
\mMonth (01–12)\dDay (01–31)
\HHour (24-hour, 00–23)\IHour (12-hour, 01–12)
\MMinute (00–59)\SSecond (00–59)
\pAM/PM\jDay of the year (001–366)
\aAbbreviated day name\ADay name
\bAbbreviated month name\BMonth name

Other C strftime format codes can also be written with \ instead of % (for example \x for the short date format).

Wildcards

SymbolMeaning
*Any string of zero or more characters
?Any single character

Matching is not case sensitive. The parts matched by the symbols can be referred to as \1, \2, … from left to right. Names without an extension (such as README) do not match *.*. A fullwidth character counts as one character.

Example: search IMG_*.jpg and replace Trip_\1.jpg turns IMG_0012.jpg into Trip_0012.jpg

Regular expressions

Perl 5 compatible regular expressions. The following can be used in the search.

SymbolMeaning
.Any single character
[abc] [^abc]Any of the listed characters / any character not listed (ranges such as [A-Z] are allowed)
^ $Start / end of the name
\< \>Start / end of a word
\b \BWord boundary / inside a word
\A \ZStart / end of the string
\d \DDigit / non-digit
\w \WAlphanumeric or _ / anything else
\s \SWhitespace / non-whitespace
\xXX \x{XXXX} \0OOA character given in hexadecimal or octal
* + ?Repeat the preceding item 0 or more / 1 or more / 0 or 1 times
{m} {m,} {m,n}Repeat the preceding item m times / at least m times / m to n times
*? +? ?? etc.Lazy match (as short as possible)
a|bEither
(...)Group. The matched part can be referred to as \1–\9
(?:...)Non-capturing group
(?=...) (?!...)Positive / negative lookahead
(?<=...) (?<!...)Positive / negative lookbehind
(?>...)Atomic group (no backtracking)
(?(condition)yes|no)Conditional pattern

By default, matching is not case sensitive (this can be changed in the options). Items that do not match are removed from the list.

Example: search ^(.*) - (.*)\.mp3$ and replace \2 - \1.mp3 swaps "Artist - Title" to "Title - Artist"

Case conversion

In the replace, you can change the case of the characters that follow.

SymbolMeaning
\u \lMake the next character upper / lower case
\U \LMake everything up to \E upper / lower case
\QTreat everything up to \E literally
\EEnd the effect of \U, \L or \Q

Example: with wildcards, search *.* and replace \1.\L\2 makes the extension lower case
