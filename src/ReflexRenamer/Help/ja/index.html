English: Reflex Renamer Help

Reflex Renamer ヘルプ

ワイルドカード・正規表現・タグ情報・スクリプトを使える、ファイルとフォルダの一括リネームツール

概要

Reflex Renamer は、たくさんのファイルやフォルダの名前をまとめて変えるための Windows アプリです。入力に合わせて新しい名前をすぐに一覧で確かめられ、実行した後でも元に戻せます。

  • リネーム：文字列や連番の追加、文字の削除、大文字・小文字や全角・半角の変換、置換。定型メニューから選ぶだけでも、ワイルドカード・正規表現・文字変換で細かく指定することもできます。
  • タグ・リネーム：音楽ファイルの ID3 タグ、写真の EXIF、Office 文書や PDF のプロパティなど、ファイルの中の情報を名前に使います。
  • 属性：ファイルやフォルダのタイムスタンプ（作成・更新・アクセス日時）と属性（読み取り専用、隠しなど）をまとめて変えます。
  • 連番オブジェクト：連番の付いた空のファイルやフォルダ、ファイルのコピーを一度に作ります。

このほか、サブフォルダ以下もまとめて処理する、別のフォルダへ移動・コピーしながら名前を付ける、日付やタグごとにフォルダを作って振り分ける、といったこともできます。

動作環境は Windows 10 / 11（64 ビット）です。画面は日本語・英語・ドイツ語・スペイン語・フランス語・イタリア語・ポルトガル語（ブラジル）・中国語（簡体字・繁体字）で表示できます。

インストールとアンインストール

インストール

インストーラー（ReflexRenamer-Setup-<版>.exe）を実行します。管理者権限は要らず、%LocalAppData%\Programs\Reflex Renamer に入ります。.NET は同梱しているので、別にインストールするものはありません。

新しい版を上書きでインストールしても、設定（Reflex Renamer.ini）と元に戻すためのログ（Rename.log）はそのまま残ります。

アンインストール

Windows の「設定」→「アプリ」から Reflex Renamer をアンインストールします。オプションで登録したフォルダの右クリックメニューと「送る」メニューの項目も、このとき取り除かれます。設定とログはインストール先のフォルダに残るので、要らなければフォルダごと削除してください。

基本的な使い方

  1. 対象を決める：「フォルダ指定」では、フォルダ一覧で選んだフォルダ（またはフォルダ欄に入力したフォルダ）の中身が対象になります。「ファイル指定」では、エクスプローラーからドロップしたファイルやフォルダだけが対象になります。エクスプローラーの検索結果をまとめてリネームしたいときに便利です。
  2. 機能を選ぶ：タブでリネーム／タグ・リネーム／属性／連番オブジェクトを選びます。
  3. 設定する：入力フォームの上から順に設定します。リネームとタグ・リネームでは、入力するたびに一覧の「新しい名前」が更新されます。名前が変わる行は太字になります。
  4. 実行する：入力フォームの下のボタンで実行します。一覧で項目を選んでいれば選んだものだけを、選んでいなければ表示しているものすべてを処理します（このときは確認のメッセージが出ます）。
ファイルやフォルダをウィンドウや Reflex Renamer のアイコンにドロップしても、そのフォルダを開けます。

リネーム

対象

  • ターゲット：ファイルとフォルダのどちらを対象にするかをチェックで選びます。
  • フィルタ：一覧に出す名前をワイルドカードで絞ります。; で区切って複数書けます（例：*.jpg;*.png）。. を含まない語は拡張子とみなすので、jpg は *.jpg と同じです。空欄と *、*.* はすべてに一致します。
  • サブフォルダ以下も対象：サブフォルダの中も一覧に入れます。「深さ」で何階層下までたどるかを決めます（0 は制限なし）。

定型メニュー

「高度なリネーム」のチェックを外しているときは、よく使う処理をツリーから選べます。

分類例
連番や文字列の追加先頭・末尾・指定位置への文字列や連番、日時、フォルダ名の追加
数字や文字列の削除指定位置の文字の削除、「 - コピー (数字)」「 - ショートカット」、[数字] (数字)、かっことその中身の削除、8.3 形式にする
文字種の変換大文字・小文字、語頭を大文字、全角・半角、ひらがな・カタカナ、アクセント記号を外す
文字列の置換指定した文字列の置き換え
数値の整理名前の中の N 番目の数字の桁をそろえる、増やす・減らす
拡張子の変更拡張子を大文字・小文字にする、削除・追加・置き換え

項目を選ぶと、必要な入力欄（追加する文字列、位置、開始番号、桁数など）が下に出ます。入力欄の下の「高度なリネーム (選択されたメニュー項目)」をクリックすると、選んでいる処理を高度なリネームの検索・置換に展開して切り替えます。細かく手直ししたいときの出発点に使えます。

高度なリネーム

「高度なリネーム」にチェックを付けると、リネーム方法を選んで検索と置換を自由に書けます。

リネーム方法使い方
ワイルドカード検索に * と ? を使い、マッチした部分を置換で \1〜\9 として参照します。名前全体と一致したものだけが一覧に残ります。→ ワイルドカード
正規表現Perl 互換の正規表現で検索し、マッチした部分を置換で置き換えます。マッチしたものだけが一覧に残ります。→ 正規表現
文字変換検索に変換前の文字、置換に変換後の文字を同じ順で並べ、1 文字ずつ置き換えます（例：検索 a-z、置換 A-Z で英小文字を大文字に）。範囲は - で書けます。

置換には、マッチした部分のほかに、名前・拡張子・フォルダ名・日時・連番などのタグを書けます。検索欄・置換欄の右のボタンを押すと、使える記号やタグがメニューで出て、選ぶとカーソルの位置に入ります。

  • 正規表現のオプション：大文字と小文字を区別するか、名前全体に一致したものだけを出すかを選べます。
  • プリセット：よく使う検索・置換の組み合わせを保存して、メニューから呼び出せます。「プリセットの整理」で並べ替え・名前の変更・削除ができます。
  • スクリプト：チェックを付けると、置換を VBScript または JScript の式として評価します。→ スクリプト

連番

置換に ? を書くと、その位置に連番が入ります。? の個数が桁数になります（??? なら 000, 001, …）。

  • 開始・ステップ：最初の番号と、いくつずつ増やすか。既定は 0 から 1 ずつです。
  • フォルダごとにリセット：サブフォルダ以下も対象にしたとき、フォルダが変わるたびに番号を振り直します。
  • 番号の種類：連番欄の右のボタンで、10 進数・16 進数・アルファベット順から選べます。

番号は一覧の並び順に振られます。列の見出しをクリックすると並べ替えられ（数字の部分は数の大きさで比べます）、見出しの右クリックメニューの「シャッフル」でランダムに並べ替えることもできます。

実行する動作

実行ボタンの左の欄で、名前を変える以外の動作も選べます。

動作内容
リネーム名前を変えます。
別フォルダに移動&リネーム選んだフォルダへ、新しい名前で移動します。
別フォルダにコピー&リネーム選んだフォルダへ、新しい名前でコピーします。
別フォルダにショートカット作成&リネーム選んだフォルダに、新しい名前のショートカットを作ります。
別フォルダにハードリンク作成&リネーム選んだフォルダに、新しい名前のハードリンクを作ります（同じドライブのみ）。
ごみ箱へ移動対象をごみ箱に移します。元に戻すボタンでは戻せません。

別フォルダへの動作では、実行ボタンを押すと送り先のフォルダを選ぶ画面が出ます。ボタンの ▼ からは、最近送ったフォルダ（最大 5 件）を選んですぐに送れます。

実行と元に戻す

  • 名前が重なったとき：新しい名前のファイルが既にあると、再試行・スキップ・すべてスキップ・上書き・すべて上書き・連番を付ける、から選ぶ画面が出ます。ツール › オプション › リネーム で、毎回聞かずに自動で連番を付けるようにもできます。
  • 失敗したとき：使用中などで名前を変えられなかったときは、再試行・スキップ・すべてスキップ・キャンセルを選べます。
  • 元に戻す：「元に戻す」ボタン（Ctrl+Z）で、直前の操作をまとめて取り消します。操作の記録は Rename.log に残るので、アプリを終了した後でも戻せます。

オプションボタンのメニューでは、連番の設定、タイムスタンプのタグに更新日時と作成日時のどちらを使うか、保護された OS のファイルを一覧に出さないか、を選べます。

タグ・リネーム

ファイルに埋め込まれた情報（タグ）を使って名前を付けます。

  1. タグの種類を選びます：ミュージック〈ID3〉、写真〈EXIF〉、イメージ〈IPTC〉、ドキュメント〈DOC〉、Web ページ〈HTML〉。
  2. 対象にする拡張子をチェックします。
  3. 「書式」に新しい名前を書きます。タグは <ID3.Artist> のように山かっこで書き、書式欄の右のボタンからメニューで選べます。新しい名前には元の拡張子が自動で付きます。
種類読み取る情報
ミュージックMP3 の ID3v1・ID3v2（2.2〜2.4）、WMA、APE、MPC、Ogg Vorbis。<ID3.*> は ID3v2 を優先し、ID3v1 だけを使いたいときは <ID3v1.*> と書きます。
写真JPEG・TIFF の EXIF（撮影日時、カメラのメーカー・機種、露出、ISO 感度など）。
イメージIPTC（キャプション、作成者、キーワードなど）。
ドキュメントWord・Excel・PowerPoint（旧形式と Office 2007 以降の形式）と PDF の文書プロパティ（タイトル、作成者など）。
Web ページHTML の <title>。

「ファイルプロパティ情報を使う」にチェックを付けると、エクスプローラーの「詳細」に出る項目（Windows やほかのアプリが追加した項目を含む）をタグとして使えます。「編集...」で、プリセットごとに使う項目と対象の拡張子を設定できます。

タグの日時の書式と、名前に使えない文字（\ / : * ? " < > |）の置き換え先は、オプション › タグ・リネーム (日付の書式と無効な文字) で変えられます。

連番・実行する動作・元に戻す・スクリプトは、リネームと同じように使えます。

属性

ファイルやフォルダのタイムスタンプと属性をまとめて変えます。「サブフォルダ以下も対象」は既定でオンです。

タイムスタンプの変え方内容
日時指定作成日時・更新日時・アクセス日時を、それぞれ指定した日時にします。
シフト今の日時から、指定した日数・時間だけ前または後にずらします。
ランダム生成下限と上限のあいだのランダムな日時にします。
連続生成開始日時から一定の間隔で、前または後へ順に日時を振ります（一覧の並び順）。
揃える作成日時・更新日時・アクセス日時・写真の撮影日時のどれかに、ほかの日時を揃えます。

シフト・ランダム生成・連続生成・揃えるは、「適用先」でチェックした日時だけを変えます。「フォルダのタイムスタンプも変更する」を付けると、フォルダ自体の日時も変えます。

属性（読み取り専用・アーカイブ・隠し・システム）のチェックは 3 状態です。グレーの項目は変更しません。「設定開始」で実行します。

連番オブジェクト

開いているフォルダに、連番の付いたファイルやフォルダを作ります。

  • 生成オブジェクトの種類：空ファイル（サイズを指定。K M G を使えます）、ファイルコピー、空フォルダ、フォルダコピー。コピーでは元にするファイルやフォルダを選びます。
  • 名前：? を書いた位置に連番が入ります。? の個数が桁数です（例：photo???.jpg）。
  • 個数・開始番号・ステップ：いくつ作るかと、番号の振り方。

作られる名前は一覧で確かめられます。「生成開始」で作ります。

便利な使い方

新しい名前の直接編集

リネームとタグ・リネームでは、一覧の「新しい名前」を手で書き換えられます。項目を選んで F2 を押すか、新しい名前の部分をクリックします。編集中に ↑ ↓ を押すと、上や下の行の編集に移れます。

フォルダ振り分け

置換（タグ・リネームでは書式）に .. や / を含む相対パスを書くと、フォルダを作ってそこへ移動できます。連番を付けるときは「フォルダごとにリセット」を付けると、振り分けたフォルダごとに 1 から数え直します。

例：写真をひとつ上のフォルダの、撮影日ごとのフォルダに振り分ける（置換 ../\Y-\m-\d/\0）

Pictures\camera\IMG001.jpg  →  Pictures\2024-05-01\IMG001.jpg
Pictures\camera\IMG002.jpg  →  Pictures\2024-05-01\IMG002.jpg
Pictures\camera\IMG003.jpg  →  Pictures\2024-05-02\IMG003.jpg

例：音楽ファイルをアーティストとアルバムごとに振り分ける（タグ・リネームの書式 <ID3.Artist>/<ID3.Album>/\t）

グループ表示

一覧の列見出しを右クリックすると、「グループで表示」でフォルダ・日付・種類・拡張子ごとにまとめられます。グループ表示にすると、連番はグループごとに振り直されます。

例：置換 \Y-\m-\d ?? で、日付でグループにした場合

2024-05-01 00.jpg
2024-05-01 01.jpg
2024-05-02 00.jpg   ← 日付が変わると 00 から
2024-05-03 00.jpg
2024-05-03 01.jpg

タグの一覧表示

タグ・リネームで一覧の列見出しを右クリックすると、メニューの後半にタグが並びます。選んだタグが列として一覧に加わり、ファイルごとの値を見比べられます。同じタグをもう一度選ぶと列が消えます。

スクリプト

「スクリプト」にチェックを付けると、置換や書式に書いた内容を VBScript または JScript の式として評価し、その結果を新しい名前にします。言語はスクリプトボタンのメニューで選びます。

  • タグは評価の前に値へ展開され、式の一部になります。文字列として扱いたいときはダブルクォーテーションで囲みます。たとえば \1 が 123 にマッチしたとき、"\1" & "\1"（JScript では "\1" + "\1"）は 123123、\1 + \1 は 246 になります。
  • 連番 ? も先に展開されます。スクリプトのときは * はランダムな数字にならず、そのまま演算子として使えます。
  • スクリプトボタンのメニューに、付属の関数（全角・半角の変換、桁そろえなど）と言語の組み込み関数が並び、選ぶとカーソルの位置に入ります。
  • 「スクリプトの編集」で、自分の関数を Script.vbs（JScript では Script.js）に書けます。保存すると次の評価から使えます。付属の関数は Script.Preset.vbs / Script.Preset.js にあり、書き方の参考になります。
  • 評価でエラーになった項目は、名前を変えません。

例：Excel ファイルの最初のシートの A1 セルの値をファイル名にする（置換 xls1stCell("\P\0") & "\e"、Script.vbs に次の関数を書く）

Function xls1stCell(path)
    Set excel = CreateObject("Excel.Application")
    Set book = excel.Workbooks.Open(path)
    xls1stCell = book.Sheets(1).Cells(1, 1).Value
    book.Close False
    excel.Quit
End Function
VBScript は Microsoft が段階的に廃止を進めています。将来の Windows で VBScript が使えなくなったときは、JScript を選んでください。

エクスプローラーとの連携

ツール › オプション › 全般 で、次の項目を登録できます。

  • フォルダのコンテキストメニュー：エクスプローラーでフォルダを右クリックしたメニューに「Reflex Renamer」が加わり、そのフォルダを開いて起動できます。
  • 「送る」メニューに追加：「Reflex Renamer (リネーム)」「(タグ・リネーム)」「(属性)」が加わり、選んだファイルを「ファイル指定」でそのページに渡せます。

このほか、お気に入り メニューに今のフォルダを登録しておくと（最大 20 件）、すぐに移動できます。表示しているフォルダの中身が変わると、一覧は自動で更新されます。

リファレンス

置換のタグ

置換（タグ・リネームでは書式）に書けるタグです。ファイルごとの値に置き換わります。

タグ意味
\0今の名前（拡張子を含む）
\tファイルタイトル（拡張子を除いた名前）
\e拡張子（. を除く）
\fファイルがあるフォルダの名前
\Fその親フォルダの名前
\Pファイルがあるフォルダのフルパス（末尾に \ が付きます。スクリプトで便利です）
\;ファイルサイズ（桁区切りあり）
\:ファイルサイズ（桁区切りなし）
\1〜\9検索でマッチした部分（ワイルドカードは記号の順、正規表現はかっこの順）
?連番。? の個数が桁数
*ランダムな数字
.. と /親フォルダ・サブフォルダへの移動（フォルダ振り分け）
\\\ そのもの

日時のタグ

ファイルの更新日時（オプションで作成日時に変えられます）に置き換わります。曜日名や月名は Windows の地域の設定に従います。\ の後ろに # を付けると先頭の 0 を省きます（\#m で 5）。

タグ意味タグ意味
\Y西暦 4 桁\y西暦の下 2 桁
\m月（01〜12）\d日（01〜31）
\H時（24 時間、00〜23）\I時（12 時間、01〜12）
\M分（00〜59）\S秒（00〜59）
\p午前／午後\j年の通算日（001〜366）
\a曜日の短い名前\A曜日の名前
\b月の短い名前\B月の名前

このほか、C 言語の strftime の書式を % の代わりに \ で書けます（\x は短い日付の形式など）。

ワイルドカード

記号意味
*0 文字以上の任意の文字列
?任意の 1 文字

大文字と小文字は区別しません。記号にマッチした部分は、左から順に \1、\2…で参照できます。拡張子のない名前（README など）は *.* に一致しません。全角文字も 1 文字として数えます。

例：検索 IMG_*.jpg、置換 旅行_\1.jpg で IMG_0012.jpg → 旅行_0012.jpg

正規表現

Perl 5 互換の正規表現です。検索では次の記号が使えます。

記号意味
.任意の 1 文字
[abc] [^abc]並べた文字のどれか／どれでもない文字（[A-Z] のように範囲も書けます）
^ $名前の先頭／末尾
\< \>語の先頭／末尾
\b \B語の境界／語の中
\A \Z文字列の先頭／末尾
\d \D数字／数字以外
\w \W英数字と _／それ以外
\s \S空白／空白以外
\xXX \x{XXXX} \0OO16 進数・8 進数で表した文字
* + ?直前の 0 回以上／1 回以上／0 回か 1 回の繰り返し
{m} {m,} {m,n}直前の m 回／m 回以上／m 回以上 n 回以下の繰り返し
*? +? ?? など最小マッチ（できるだけ短く）
a|bどちらか
(...)グループ。マッチした部分を \1〜\9 で参照できます
(?:...)参照しないグループ
(?=...) (?!...)肯定・否定の先読み
(?<=...) (?<!...)肯定・否定の後読み
(?>...)バックトラックしないグループ
(?(条件)真|偽)条件によって分かれるパターン

既定では大文字と小文字を区別しません（オプションで変えられます）。マッチしなかった項目は一覧から外れます。

例：検索 ^(.*) - (.*)\.mp3$、置換 \2 - \1.mp3 で「アーティスト - 曲名」を「曲名 - アーティスト」に入れ替え

大文字・小文字の変換

置換の中で、続く文字の大文字・小文字を変えられます。

記号意味
\u \l次の 1 文字を大文字／小文字に
\U \L\E までを大文字／小文字に
\Q\E までを文字どおりに扱う
\E\U \L \Q の効果を終える

例：ワイルドカードで検索 *.*、置換 \1.\L\2 で拡張子を小文字に

キー操作

キー動作
F2新しい名前を直接編集
F5フォルダ一覧を最新の状態にする
Ctrl+Z元に戻す
Ctrl+Aすべて選択
Ctrl+I選択を反転
Del選んだ項目を一覧から外す（ファイルは消えません）
Alt+F4終了

一覧の項目をダブルクリックすると関連付けられたアプリで開き、右クリックするとエクスプローラーと同じメニューが出ます。

設定とファイル

Reflex Renamer は、自分のフォルダ（インストール先）に次のファイルを作ります。

ファイル内容
Reflex Renamer.ini設定。ウィンドウの位置と大きさ、入力欄の履歴、プリセット、お気に入りなど。終了するときに保存します。
Rename.log元に戻すための操作の記録。
Script.vbs / Script.js「スクリプトの編集」で書いた自分の関数。

言語は ヘルプ › 言語 で変えられます（次に起動したときに反映されます）。最初は Windows の表示言語に合わせます。ウィンドウやペインの配置を最初の状態に戻すには、ツール › ウィンドウレイアウトのリセット を使います。

Reflex Renamer について

Reflex Renamer は、Naru 氏の Flexible Renamer にインスパイアされたソフトウェアです。

版は ヘルプ › Reflex Renamer のバージョン情報 で確かめられます。
