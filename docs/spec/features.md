# 機能一覧（オリジナル版 Flexible Renamer v8.4）

移植の対象となる機能をすべて列挙する。タスク（[docs/tasks.md](../tasks.md)）は、この一覧の ID を参照する。

## 情報源

| 記号 | 情報源 | 取得方法 |
|---|---|---|
| R | exe のリソース（ダイアログ、メニュー、アクセラレータ、ツールバー） | [resources.md](resources.md)（`FrTools res-dump` で生成） |
| S | UI 文字列（メッセージ、ツールチップ、定型処理名、タグ名） | `FlexRenamer/Flexible Renamer.JA.Strings.ini` など |
| H | ヘルプ（CHM）。詳細仕様と変更履歴 | `7z x` で展開した `.work/help/ja.txt` |
| U | 実際に動かして観察した画面と動作 | `FrTools run explore-pages original` など |
| D | 付属データ（Preset.ini、TagDef.ini、Script.Preset.vbs） | `FlexRenamer/` |

検証方法の列の意味:
- **単体**：Core のユニットテスト
- **正解**：オリジナル版のプレビュー一覧（新しい名前の列）を UI Automation で読み、移植版の結果と照合する（`FrTools compare`）
- **画面**：スクリーンショットと UI ツリーを比較する（`FrTools compare`）
- **手動**：自動化が難しいので人が確認する（シェル連携など）
